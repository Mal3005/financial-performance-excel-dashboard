# Financial Performance Analysis – Interactive Excel Dashboard

## Project Overview
This project presents an interactive financial dashboard developed in Microsoft Excel to analyse the financial performance of a business operating in the USA and Canada.

The dashboard provides insights into revenue, gross profit, EBITDA, margins and service-line performance.

## Project Objectives
- Analyse revenue and profitability across countries.
- Compare revenue and EBITDA trends.
- Evaluate service-line performance.
- Analyse gross profit and EBITDA margins.
- Support business decisions through interactive reporting.

## Tools & Techniques
- Microsoft Excel
- PivotTables and PivotCharts
- Interactive Slicers
- Lookup Functions
- GETPIVOTDATA
- Financial Analysis
- Dashboard Design

## Key Financial Results

| Metric | Result |
|---|---:|
| Total Revenue | £1,730,862 |
| Gross Profit | £1,044,085 |
| EBITDA | £273,780 |
| Gross Profit Margin | 60.3% |
| EBITDA Margin | 15.8% |

## Key Business Insights
- The USA is the largest revenue contributor, generating £1,494,164.
- Canada generates £236,698 in revenue.
- Gross profit margin is approximately 63% in Canada and 60% in the USA.
- EBITDA margins are approximately 16% in both markets.
- Marketing revenue in the 2024 forecast decreases by approximately 24.7% compared with 2023.

## Recommendations
- Investigate the forecast decline in Marketing revenue.
- Explore opportunities to increase revenue in Canada.
- Monitor profitability across individual service lines.
- Use interactive dashboard filters for ongoing financial performance reviews.
